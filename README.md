# Professional Portfolio

A responsive personal portfolio website built with **HTML5, CSS3 and Bootstrap 5**.

## Features

- Responsive navigation bar
- Hero section
- About Me section
- Skills section
- Projects section
- Education timeline
- Contact section
- Responsive design for desktop, tablet and mobile

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## How to run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation is required.

## Customize before submission

Open `index.html` and replace:

- `Nada Bdeir` with your full name.
- `Fourth-Year Information Systems Student` with your real specialization.
- `Delta University - Egypt` with your university.
- `student@example.com` with your real email.
- GitHub and LinkedIn links with your real profile links.
- Project names and descriptions with your actual projects.

You can also replace the initials avatar with a personal photo if you want.
